Sobre o Projeto

O **SODA - Slider Premium** é um projeto front-end desenvolvido com o objetivo de explorar animações imersivas, performance de ponta e design moderno. Através do ecossistema React injetado via CDN, o projeto utiliza intensamente a biblioteca **GSAP (GreenSock Animation Platform)** em conjunto com o **ScrollTrigger** para entregar transições marcantes e efeitos visuais contínuos mapeados na rotação de tela do usuário (scroll). O layout foca em um banner hero fluído e elegante.

A interface possui um carrossel de refrigerantes sofisticado planejado para destacar o produto nos mínimos detalhes – cobrindo marcas famosas do mercado, com elementos visuais de impacto como gotas, splashes d'água e animações em SVG altamente otimizadas e traçadas com precisão matemática.

##  Principais Funcionalidades

- **Animações Dinâmicas por Scroll**: Linhas SVG orgânicas desenhadas progressivamente guiando elementos visuais da tela à medida que o usuário rola a página, criando forte sinergia entre o conteúdo.
- **Transições Interativas (Hover)**: Elementos construídos com responsividade imaculada que ativam visuais expandidos de alta qualidade, garantindo que o produto principal preencha visualmente o quadro com movimentos amigáveis.
- **Interface Glassmorphism & Premium Design**: Elementos de composição como curvas graciosas, efeitos de desfoque, paletas de cores refinadas e composições tipográficas arrojadas unindo tudo numa interface premium.
- **Red Ribbon Animada**: Destaque sutil com uma fita vermelha sofisticada baseando a harmonia estética da assinatura ou de detalhes do site na base do slider principal.
- **Configuração Sem Build (No-Bundler)**: Elaborado utilizando `Babel Standalone` para compilação no front-end em tempo real para rápida prototipação de UI.

##  Tecnologias Utilizadas

- **React 18** (Construção da UI)
- **Babel via CDN** (Transpilação instantânea do script JSX)
- **GSAP 3.12 & ScrollTrigger** (Micros e macro animações avançadas)
- **Vanilla CSS3** (Propriedades modernas, Flexbox, Animações e Variáveis de estado CSS)
- **BoxIcons** (Estética Vetorial Minimalista)
- **Google Fonts: Montserrat** (Tipografia moderna focada em legibilidade elegante)

## Como Iniciar (Setup)

Este projeto foi intencionalmente projetado focado em visualização sem fricção das animações. Não é necessário empacotadores longos npm (`npm install`). Tudo corre com elegância assim que aberto no browser.

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com/seu-usuario/slider-refrigerante.git
   ```
2. Navegue até a pasta:
   ```bash
   cd slider-refrigerante
   ```
3. Para uma experiência completa devido às restrições do CORS quando exibindo SVGs, inicie utilizando qualquer roteador local.

<details>
<summary>Comando usando PHP (se você tem o XAMPP, p.ex.)</summary>

```bash
php -S localhost:8000
```
</details>

<details>
<summary>Comando usando Python/Node</summary>

```bash
python -m http.server
# ou
npx serve
```
</details>

Após inicializar, abra e desfrute com `http://localhost:8000/`.
